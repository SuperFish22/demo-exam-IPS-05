# Подготовка к демоэкзамену 09.02.07 «Программист»

Учебный сайт для студентов: теория, разобранные примеры и тренажёры в браузере.
Сайт статический: HTML, CSS и JavaScript, без сервера и без сборки.

## Разделы
| Файл | Что внутри |
|---|---|
| `index.html` | Главная: модули экзамена, план занятий, список тренажёров |
| `enterprise.html` | Как работает предприятие, «Детектив документов», калькулятор заказа |
| `er.html` | Алгоритм построения ER, проверка имён, квиз по 3НФ, эталонная схема, мини-кейсы |
| `sql.html` | Типы данных, schema.sql, импорт JSON, запрос модуля 3, SQL-песочница |
| `wpf.html` | WPF, Npgsql, три вида сообщений, симулятор окна входа с капчей |
| `integration.html` | Эмулятор, проверка ФИО, ТестКейс.docx, свой API и тесты Postman |
| `variants.html` | Задание «пакет документов своего предприятия» и список из 60 вариантов |
| `practice.html` | Шесть пакетов документов для самостоятельной практики (`materials/`) |
| `checklist.html` | Чек-лист перед сдачей, шаблоны README и документации |

## Публикация на GitHub Pages
1. Создайте на GitHub новый публичный репозиторий, например `de-09-02-07`.
2. Загрузите в него все файлы этой папки (кнопка **Add file → Upload files**, перетащите содержимое папки целиком) и нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/de-09-02-07/`.

Или через командную строку:
```bash
git init
git add .
git commit -m "Сайт подготовки к ДЭ"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/de-09-02-07.git
git push -u origin main
```

## Как менять содержимое
Каждая страница — обычный HTML-файл в корне папки. Откройте нужный файл в любом редакторе (VS Code, Notepad++), поправьте текст и сохраните. Сборка не нужна.

- Общие стили: `assets/style.css`.
- Общие скрипты (кнопка «Копировать», окно сообщений): `assets/app.js`.
- Меню сверху повторяется в каждой странице. Если добавляете новую страницу, добавьте ссылку на неё в блок `<nav class="top">` во всех файлах.
